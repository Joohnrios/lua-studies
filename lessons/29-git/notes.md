# Aula 29 — Práticas de Git

Um commit deste repositório guarda uma aula. A primeira linha é um imperativo em inglês. A linha seguinte fica em branco. O corpo diz por que a mudança existe.

Antes de gravar, olhe o que vai entrar. Segredo, log e rascunho do `playground` ficam de fora. O `.gitignore` já lista `*.log` e `playground/*`.

O autor do commit é a pessoa. Uma linha `Co-authored-by` de outra conta não entra na mensagem.

Referência do formato usado aqui: o histórico em `main`.
